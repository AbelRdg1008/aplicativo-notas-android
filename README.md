# Arena Arcana

Jogo de duelo de cartas em português, num único `index.html`, sem dependências ou pedidos externos. Abra o HTML num navegador moderno. Para desenvolvimento local opcional: `python3 -m http.server 8000 --directory /workspace/aplicativo-notas-android`.

No iPhone, disponibilize o arquivo numa hospedagem HTTPS, abra o endereço no Safari e use Compartilhar → Adicionar à Tela de Início. O projeto está preparado para GitHub Pages: em Settings → Pages, selecione Deploy from a branch, branch `main`, pasta `/ (root)` e Save. O endereço previsto é https://abelrcanjao-ops.github.io/aplicativo-notas-android/; só use após o GitHub confirmar a implantação. A execução local não precisa de servidor; a instalação pela Tela de Início precisa de um endereço acessível ao Safari.

Toque nas cartas para ver ações. Segure por 220 ms para espiar, deslize para outra carta e solte para fechar. Durante animações, toque para avançar. Selecione alvos ou tributos destacados no campo, ou use Cancelar. A ajuda inclui regras, equilíbrio e coleção. Vitórias e derrotas são guardadas no armazenamento local quando permitido pelo navegador.

Inclui 72 monstros, 36 magias e 17 armadilhas, decks sorteados de 40 cartas, oponentes com 10.000 PV e Oráculo automático. As ilustrações usam 40 artes originais de fantasia, geradas em duas pranchas e incorporadas como JPEG no próprio HTML. As 125 cartas compartilham essas bases por família de criatura ou efeito; ainda não há uma ilustração exclusiva para cada carta. O canvas recorta os painéis e aplica acabamento leve por atributo. O campo tem acabamento de pedra gravada, zonas compactas e cartas com moldura, nome, nível, ilustração, descrição e ATK/DEF. Fontes locais mantêm o arquivo independente de Google Fonts.

Validação: Chromium com viewport móvel 390×664, testes isolados dos 53 efeitos de magias/armadilhas, cálculos de batalha, esgotamento de deck, 12 duelos completos e interação por toque (invocação, seleção de alvo, baixar armadilha, turno do Oráculo e abas da coleção). Scripts e captura da validação estão em `/workspace/scratch/arena-tests` nesta máquina. A instalação do WebKit foi bloqueada pela política de rede; teste num iPhone físico ainda é necessário. A revisão visual também foi validada em 320×568, 375×667, 390×664, 430×932 e 820×1180, com controles visíveis e sem transbordamento. O HTML tem aproximadamente 2 MB e não baixa as imagens durante o jogo.
